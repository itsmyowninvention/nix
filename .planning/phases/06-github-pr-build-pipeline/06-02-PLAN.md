<objective>
Replace `nix build` with `nix eval` in GitHub Actions CI to validate that all platform configurations (NixOS and Darwin) evaluate correctly without the time-consuming actual build. Remove the entire build job and merge eval verification into the check job.

Purpose: Reduce CI time from 60+ minutes to a few minutes while still validating configuration correctness. `nix eval` verifies all module imports resolve, options are valid, and derivations can be computed - catching most configuration errors without building.
Output: Fast CI pipeline with eval-based verification for both platforms.


    2. **Add nix eval steps after existing checks** (add after statix step, before job end):
    ```yaml
      - name: Evaluate NixOS configuration
        if: matrix.config == 'nixos'
        run: nix eval .#nixosConfigurations.nixos.config.system.build.toplevel.drvPath --raw

      - name: Evaluate Darwin configuration
        if: matrix.config == 'darwin'
        run: nix eval .#darwinConfigurations.zhaochanglongdeMacBook-Air.config.system.build.toplevel.drvPath --raw
    ```

    3. **Remove the entire build job** (lines 44-74 in current file):
    - Delete everything from `build:` to the end of the file
    - This removes: the build job definition, DeterminateSystems actions, cache setup, and build steps

    **Final structure should be:**
    ```yaml
    name: Nix CI

    on:
      push:
        branches: [main]
      pull_request:

    concurrency:
      group: ${{ github.workflow }}-${{ github.ref }}
      cancel-in-progress: true

    jobs:
      check:
        strategy:
          matrix:
            include:
              - os: ubuntu-latest
                system: x86_64-linux
                config: nixos
              - os: macos-latest
                system: aarch64-darwin
                config: darwin
        runs-on: ${{ matrix.os }}
        timeout-minutes: 30

        steps:
          - name: Checkout
            uses: actions/checkout@v4

          - name: Install Nix
            uses: cachix/install-nix-action@master
            with:
              nix_path: nixpkgs=channel:nixpkgs-unstable
              extra_nix_config: |
                experimental-features = nix-command flakes

          - name: Check flake validity
            run: nix flake check --no-build --system ${{ matrix.system }}

          - name: Check Nix formatting
            run: nix run nixpkgs#alejandra -- --check .

          - name: Run statix linter
            run: nix run nixpkgs#statix -- check .

          - name: Evaluate NixOS configuration
            if: matrix.config == 'nixos'
            run: nix eval .#nixosConfigurations.nixos.config.system.build.toplevel.drvPath --raw

          - name: Evaluate Darwin configuration
            if: matrix.config == 'darwin'
            run: nix eval .#darwinConfigurations.zhaochanglongdeMacBook-Air.config.system.build.toplevel.drvPath --raw
    ```

    **Why this works:**
    - `nix eval ...drvPath --raw` evaluates the derivation and outputs its store path
    - This verifies all module imports resolve, options are valid, types check
    - Much faster than `nix build` (seconds vs 60+ minutes)
    - Catches configuration errors without the build overhead

    **Do NOT modify:** The format check, statix check, or flake check steps - these remain unchanged.
