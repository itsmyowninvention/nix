<task type="auto" tdd="true">
  <name>Task 1: Make sops configuration conditional for CI</name>
  <files>nixos/sops.nix, darwin/sops.nix</files>
  <behavior>
    - Test 1: sops.age.sshKeyPaths is empty list when SSH key does not exist
    - Test 2: sops.age.sshKeyPaths contains expected path when SSH key exists
    - Test 3: Build succeeds without SSH key present (CI environment)
  </behavior>
  <action>
    Modify both sops.nix files to make the SSH key path conditional using `lib.pathExists`.

    **For nixos/sops.nix:**
    Add `lib` to the function arguments and wrap the sshKeyPaths assignment:
    ```nix
    { inputs, self, config, lib, ... }:
    {
      imports = [ inputs.sops-nix.nixosModules.sops ];

      # Only configure SSH key paths if the key exists (not in CI)
      sops.age.sshKeyPaths = lib.mkIf (lib.pathExists "/root/.ssh/id_ed25519") [ "/root/.ssh/id_ed25519" ];

      # Keep existing secrets configuration unchanged
      sops.secrets = { ... };
    }
    ```

    **For darwin/sops.nix:**
    Add `lib` to the function arguments and wrap the sshKeyPaths assignment:
    ```nix
    { inputs, lib, ... }:
    {
      imports = [ inputs.sops-nix.darwinModules.sops ];

      # Only configure SSH key paths if the key exists (not in CI)
      sops.age.sshKeyPaths = lib.mkIf (lib.pathExists "/var/root/.ssh/id_ed25519") [ "/var/root/.ssh/id_ed25519" ];
    }
    ```

    **Why this works:**
    - `lib.pathExists` checks if the SSH key file exists at Nix evaluation time
    - `lib.mkIf` returns an empty list when the condition is false
    - sops-nix gracefully handles empty `sshKeyPaths` by not attempting decryption
    - In CI, SSH keys don't exist, so secrets are not decrypted, but the derivation still builds

    **Important:** This change is safe for local development because the SSH keys exist on actual machines.
  </action>
  <verify>
    <automated>nix eval .#nixosConfigurations.nixos.config.sops.age.sshKeyPaths --json 2>&1 | grep -q '\[\]'</automated>
  </verify>
  <done>
    - nixos/sops.nix uses lib.mkIf with lib.pathExists for sshKeyPaths
    - darwin/sops.nix uses lib.mkIf with lib.pathExists for sshKeyPaths
    - nix eval shows empty sshKeyPaths when SSH key doesn't exist
  </done>

<task type="auto">
  <name>Task 2: Add build job to CI with caching</name>
  <files>.github/workflows/ci.yml</files>
  <action>
    Add a new `build` job to the CI workflow that runs after the `check` job passes. Use DeterminateSystems actions for better caching integration.

    **Key changes to .github/workflows/ci.yml:**

    1. **Add build job with job dependency (place after the check job):**
    ```yaml
      build:
        needs: check  # Only run after fast checks pass
        strategy:
          matrix:
            include:
              - os: ubuntu-latest
                system: x86_64-linux
                config: nixos
              - os: macos-latest
                system: aarch64-darwin
                config: darwin
        runs-on: ${{ matrix.os }}
        timeout-minutes: 60  # Builds can take longer

        steps:
          - name: Checkout
            uses: actions/checkout@v4

          - name: Install Nix
            uses: DeterminateSystems/nix-installer-action@main

          - name: Setup Nix Cache
            uses: DeterminateSystems/magic-nix-cache-action@main

          - name: Build NixOS configuration
            if: matrix.config == 'nixos'
            run: nix build .#nixosConfigurations.nixos.config.system.build.toplevel

          - name: Build Darwin configuration
            if: matrix.config == 'darwin'
            run: nix build .#darwinConfigurations.zhaochanglongdeMacBook-Air.config.system.build.toplevel
    ```

    2. **Why DeterminateSystems actions:**
    - `nix-installer-action@main`: Faster installation (~4s Linux, ~20s macOS), KVM support, flakes enabled by default
    - `magic-nix-cache-action@main`: Zero-configuration free GitHub Actions cache, works with forks, no Cachix account needed

    3. **Fast-fail principle preserved:**
    - `needs: check` ensures build only runs after fast checks (format, lint, flake check) pass
    - Build job timeout is 60 minutes (longer than check's 30 minutes)

    4. **Platform-specific build commands:**
    - NixOS: Builds on ubuntu-latest using `.#nixosConfigurations.nixos`
    - Darwin: Builds on macos-latest using `.#darwinConfigurations.zhaochanglongdeMacBook-Air`

    **Do NOT change the check job** - keep using `cachix/install-nix-action@master` to avoid breaking existing fast checks.
  </action>
  <verify>

  </verify>
